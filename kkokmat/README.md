# 꼭맞 — 국내 영유아복 사이즈 비교

12개 브랜드 공식몰의 공개 상품 목록 8,351개와 상품 치수 자료를 모은 모바일 웹입니다. 2,539개 상품에서 수치 자료를 확보했고, 비교에 필요한 부위를 갖춘 상품은 1,852개(아동용 1,850개)입니다. 사이즈별 치수 행은 9,951개입니다. 전체 목록 수는 의류 외 용품을 포함하며 실제 비교 가능 수와 다릅니다. 상품별 출처와 확인일을 보존합니다.

2026-11-23 모이몰른 주요 실내복의 공식 이미지 실측을 직접 판독해 16종·91개 사이즈 행을 추가했습니다. 기존 12종을 포함해 총 28종을 비교할 수 있습니다. 아가방은 주요 겨울 내의 12종과 7부 내의 1종의 공식 상세 이미지를 확인했으나, 해당 상품의 가슴·총장·바지 길이 실측표가 없어 비교 데이터로 추가하지 않았습니다. 공통 신체 권장표를 상품 실측으로 대체하지 않습니다. 검수 원본 주소·이미지 해시·전사 수치는 `research/homewear-reviewed-20261123.json`, 재적용은 `node scripts/apply-homewear-reviewed.mjs`를 사용합니다. 아가방 전상품에 실측이 없다는 뜻은 아닙니다.

## 실행

새 PC는 [최신 인수인계](../다른-PC에서-이어가기.md)를 먼저 따라 로컬 Site 정보와 DB 3개 마이그레이션을 준비하세요. 로그인 키는 [로그인 설정](SOCIAL-LOGIN-SETUP.md)의 Git 제외 환경 파일에서 관리합니다.

Node.js 22.13 이상에서 `npm ci`, `npm run build`로 준비합니다. 계정 저장은 Worker와 D1을 사용합니다. `npm start`로 로컬 Worker를 실행하며, 첫 로컬 데이터베이스 준비 및 선택 로그인 미리보기는 [계정 기능 실행 안내](ACCOUNT-FEATURES.md)를 참고하세요. `npm test`로 데이터·매칭 규칙·계정 접근 제한을 검증합니다. 정적 앱과 공개 데이터의 원본은 `public/`, 생성된 배포 결과는 `dist/client/`와 `dist/server/`입니다.

## 데이터

- `dist/data.json`: 공개 데이터베이스. 신체 기준표와 상품 실측 분리, 원본 둘레 값 보존, 출처·확인일·측정 한계 포함.
- `dist/catalog.json`: 모든 수집 상품의 출처·분류·치수 확보 여부·브랜드별 수집 범위.
- `research/catalog-*.json`: 각 공식몰의 공개 목록·상세 수집 결과. URL과 수집 완료 여부를 보존합니다.
- `scripts/harvest.mjs`: 공개 목록 페이지를 순회하는 수집 도구. `node scripts/harvest.mjs apricot`처럼 실행합니다. 수집 시점·캐시 갱신 여부는 운영자가 검토해야 합니다.
- `dist/measurements.csv`: 상품 실측을 단면 기준으로 통일한 CSV.
- `dist/engine.js`: 브라우저와 Node에서 공유하는 비교 규칙.
- `dist/app.js`: 입력, 결과, 인접 사이즈 비교, 브랜드 데이터 검색, 브라우저 내 저장.

브랜드별 지정 공개 카테고리를 수집한 결과이며, 삭제·비노출 상품이나 과거 전체 판매 이력을 보장하지 않습니다. 유니클로는 한국 베이비 카테고리의 동적 목록 중 확인된 88개 상품이며 전체 판매 수를 보장하지 않습니다. 모이몰른은 공식 공개 목록 API를 사용하고 색상 중복·광고 항목·명시적인 타 브랜드를 제거했습니다. 재고·가격의 실시간 연동은 없습니다. 이미지로만 제공되어 수치를 확인하지 못한 자료는 추측하지 않고 미확보로 표시하며, 확보한 공식 이미지 링크를 제공합니다. 특히 아가방과 모이몰른의 전체 실측을 확보했다는 뜻은 아닙니다.

## 비교 규칙과 한계

1. 실내복 세트·상의·하의·바디수트·원피스·모자·양말을 구분하고 같은 종류와 대상(아동/성인)끼리만 비교합니다. 세트는 가슴·상의·바지 길이가 필요하고, 상의는 가슴·상의 길이, 하의는 허리·바지 길이가 필요합니다. 비교 부위의 절대 차이 평균이 작은 후보를 선택하며, 세트 허리는 표에만 표시합니다.
2. 둘레는 2로 나눠 단면 비교값으로 환산하며 원본을 보존합니다. 브랜드별 측정 지점이 완전히 같다는 뜻은 아닙니다.
3. 현재 옷이 작으면 주요 치수가 모두 같거나 큰 사이즈 중 한 부위 이상 0.5cm 큰 후보를, 여유가 많으면 반대로 작은 후보를 찾습니다. 조건을 만족하는 상품별 가장 가까운 사이즈를 추천하며, 방향이 섞이거나 해당 사이즈가 없으면 반환하지 않습니다. 실제 착용 적합성을 보장하는 예측 모델은 아닙니다.
4. 키·체중 모드에서는 두 입력값을 모두 받아 공식 신체 기준표에서 각각 판정하고 근거를 따로 표시합니다. 체중 자료 미공개·단일 기준값은 전체 조건을 검증한 추천과 구분합니다. 아가방의 공개된 단일 기준체중도 키와 별도로 대조하되 허용 범위를 만들지 않습니다. 현재 잘 맞는 옷의 브랜드·사이즈가 같은 브랜드 기준표와 충돌하면 작은 호칭을 바로 추천하지 않습니다. 타 브랜드의 숫자 호칭을 직접 환산하지 않습니다. 87cm·15kg 사례에서 코니 키 기준 90과 체중 기준 100이 충돌하는 회귀 검증을 포함합니다.
5. 아가방 단일 기준키는 '가장 가까운 기준키'로만 표시하고 범위를 만들지 않습니다. 아가방 영아 체중과 밍크뮤 불일치 연령대는 제외했습니다.
6. 세탁 수축·신축성·성장 예측·날씨는 자동 반영하지 않습니다. 실제 착용 검증 전에는 반품률 감소나 정확도를 주장할 수 없습니다.
7. 아프리콧 스튜디오는 키 기준표만 공개되어 체중에 따른 추천을 하지 않습니다. 3M의 '~55cm'는 하한 미공개 상태를 유지합니다. 공식 실측의 비단조 수치는 임의 보정하지 않습니다.
8. 아기띠·턱받이·잡화도 목록에 포함하지만 의류 기준으로 사이즈를 환산하지 않습니다. 성인·아동 혼합 구성은 자동 매칭에서 제외합니다.
9. 다른 원단은 확인된 주요 소재 종류 또는 원단 조직이 다른 상품을 뜻합니다. 혼용률·색상 차이만으로 구분하지 않습니다. 기준 원단을 확인할 수 없거나 직접 입력한 치수라면 사용자가 원단을 선택합니다. 소재 미확인 상품은 해당 필터에서 제외합니다.
10. 계절 선택은 공식 상품명·설명의 착용 용도·보온·통기 원단 표현을 근거로 합니다. 사계절 상품은 개별 계절에도 포함하며, 미확인 상품과 단순 출시 계절은 분류하지 않습니다. 성장·기상 예측은 하지 않습니다.
11. 각 결과의 특징 뱃지는 공식 상품 설명 또는 제조국 정보의 근거를 보존합니다. 국내·해외 제조국이 함께 표시되면 국내생산 뱃지를 붙이지 않습니다. 확인되지 않은 특징은 '특징 확인 중'으로 표시합니다. `research/product-attributes.json`과 `dist/data.json`의 `attributes`에 출처와 판단 근거가 있습니다. `node scripts/enrich-attributes.mjs`는 수집 당시 공식 HTML 캐시에서 속성을 추출하며 이후 `node build-data.mjs`로 반영합니다.
12. 입던 옷 비교에서도 키·체중을 선택 입력해 교차 확인할 수 있습니다. 실제 잘 맞는 옷의 실측을 우선하고, 신체 기준표와 다른 경우 그 차이를 표시합니다. 키만으로 실측 후보를 더 작은 사이즈로 덮어쓰지 않습니다. 결과는 12개씩 더 볼 수 있으며, 브랜드·종류별 실제 비교 가능한 상품 수를 입력 단계와 데이터 화면에 표시합니다.

비회원 비교의 입력값은 브라우저에서 처리하며, 비회원이 선택한 브라우저 저장은 localStorage를 이용합니다. 선택 로그인 후에는 아이 프로필과 입던 옷을 계정에 저장할 수 있고, 완료한 비교의 입력·결과는 계정별 비교 기록에 저장합니다. 기존 브라우저 저장은 사용자가 복사 버튼을 누를 때만 계정으로 옮깁니다. 저장 데이터는 서버에서 로그인한 소유자로 제한합니다. 자세한 기능과 저장 범위는 [계정 기능 안내](ACCOUNT-FEATURES.md)를 참고하세요. 외부 폰트가 차단되면 시스템 폰트를 사용합니다.

13. 베네베네 Baby·Toddler 신체표는 공식 up to 상한만 보존하고, 이를 모두 넘지 않는 최소 호칭을 참고값으로 표시합니다. 하한을 만들지 않고 Junior의 상충하는 6T 기준은 합치지 않습니다. Chest/Waist 실측은 원문을 그대로 기록하며 단면 해석·측정 위치 확인 필요 문구를 결과에 표시합니다.
14. 슈슈앤크라의 공식 24M·2Y는 같은 신체 범위에서도 별도 호칭을 유지합니다. 구성별 치수가 다른 묶음 상품은 자동 매칭에서 제외합니다.
15. 얼스는 공식 이미지 직접 판독 14개 상품 중 13개를 비교합니다. 동일한 이미지 URL을 실제로 공유하는 색상만 같은 치수표를 적용합니다. 목선 기준 소매는 raw에만 보존하며, 충전재를 누른 패딩 측정 방법도 안내합니다. 공통 신체표는 미확보이므로 모델 착용 사례로 권장 범위를 만들지 않습니다.
16. 유니클로는 한국 공식 제품 실측표와 신체표를 분리합니다. 체중 단일값은 범위로 변환하지 않습니다. 인심·등 중심 소매는 총장·일반 소매로 대입하지 않고 원본에 보존하며, 필수 치수가 부족한 세트·하의는 자동 매칭에서 제외합니다.
