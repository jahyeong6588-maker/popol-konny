# 공통 측정 부위 비교

2026-11-23. 유니클로의 공개 실측이 있어도 바지 총장 필수 조건 때문에 하의·파자마가 선택되지 않던 문제를 수정했다.

- 의류 한 사이즈에 실제 치수 2곳 이상이 있으면 기준·후보로 선택할 수 있다. 모자·양말은 지원 측정 부위가 1곳이다. 나이·표준 신체표로 옷 치수를 만들지 않는다.
- 같은 종류·아동/성인 구분·착용 조건을 유지하면서 양쪽에 공통으로 있는 측정 키만 차이·점수·크기 방향 계산에 사용한다. 공통 부위가 하나도 없으면 결과에 포함하지 않는다.
- 인심과 바지 총장, 일반 소매와 등 중심 소매는 다른 키다. 상의 전체 길이를 바지 총장에 복사하거나 인심과 밑위를 더하지 않는다.
- 한쪽에 없는 항목은 `미확인`, 차이는 `비교 안 함`으로 표시한다. 주요 부위가 빠지거나 한쪽에만 있는 부위가 있으면 일부 치수 비교라고 안내한다. 한 공통 부위의 차이가 0이라고 여러 부위를 비교한 후보보다 먼저 올리지 않는다.
- 전체 주요 치수의 근접성과 일부 부위의 근접성을 구분한다. 일부 치수 결과에는 `공통 N곳 비교`를 표시하고, 숫자 표는 기본 접힘을 유지한다.
- 유니클로 공개 표의 인심·엉덩이·허벅지·밑위·밑단·어깨·등 중심 소매를 원본에서 읽어 별도 필드로 보존한다. 원문과 기존 상품 ID를 유지한다. 허리·엉덩이는 둘레가 명시된 경우에만 2로 나눈다.
- 옷장 저장 API도 새 측정 키를 보존한다. 계정·자녀·데이터베이스 스키마·OAuth 설정은 바꾸지 않는다.

현재 확보 데이터 기준 유니클로 상의 13상품/45사이즈, 하의 28상품/117사이즈, 실내복 세트 17상품/68사이즈가 공통 부위 비교에 포함된다. 이는 새 실측 수집 개수가 아닌, 기존 원본을 활용해 비교 가능 범위를 넓힌 집계다. 타 브랜드도 같은 기준이 적용되며, 아가방처럼 옷 실측 자체가 없는 브랜드는 계속 제외한다.

상품·사이즈별 미확인 항목은 별도 Markdown/JSON에 작성했다. 원본 수집 후 `scripts/normalize-shared-measurements.mjs`를 실행하면 필드·상품 목록의 비교 가능 여부와 보고서·CSV를 함께 갱신한다.
