# 모나마켓 신체 기준 참고 후보

확인일 2026-11-24. 원문은 https://monamarket.co.kr/product/brand-size-guide.html 이며 제조사 실측표가 아닌 **판매처의 브랜드별 신체 가이드**입니다.

## 수집 범위

- 가이드에 표시된 63개 브랜드 중 명확한 양끝 키/체중 범위를 갖춘 54개 브랜드의 가이드를 사용합니다.
- 공개 베베(cate_no=118)·키즈(cate_no=266) 목록 113페이지에서 중복을 뺀 3,002개 항목을 조사했습니다.
- 명시적인 주니어·여성, 잡화, 상품 종류 미분류, 대응 가이드 없음, 목록 품절 표시 등을 걸러 45개 브랜드의 의류 1,648개를 보관했습니다. 1,647개는 상세페이지의 실제 사이즈 옵션을 확인했습니다. 옵션 미확인 1개는 자동 후보에서 제외합니다.
- 서비스 대상은 만 0~5세입니다. 나이가 명시된 표는 시작 연령이 72개월 이상인 행을 제외합니다. 연령이 없는 표에는 판매처의 베베/키즈 분류와 원문 신체 범위를 보존하며 키를 나이로 환산하지 않습니다. 따라서 모든 상품이 만 0~5세 전용임을 보증하는 분류는 아닙니다.
- 모델 착용 사례, 연령만 있는 표, 부위/단위 불명확, 단일 참고점, 상한만 있는 표는 자동 추천 범위로 바꾸지 않습니다. 원본 표의 신체 범위를 의류 실측으로 복사하지 않습니다.
- 베베 전용 브랜드명이 따로 있는 경우 상위 브랜드명과 섞지 않습니다. 아동/베베·니트·오버롤 등 표가 분리되면 해당 구분을 확인합니다.

## 화면과 계산

입던 옷 비교의 1단계에 키·체중 선택 입력과 참고 후보 안내를 제공합니다. 입력하지 않아도 기존 비교를 계속합니다. 키가 있으면 결과 아래 별도 “키·체중으로 함께 찾아봤어요” 영역을 표시합니다.

가이드에 키·체중이 모두 있으면 두 범위를 모두 충족해야 하며, 체중 입력이 없으면 해당 가이드는 보류합니다. 키만 공개한 가이드는 키 기준으로 표시하고 체중 미공개를 알립니다. 경계에서 호칭이 겹치면 여러 사이즈를 그대로 보여줍니다. 상품 상세에서 확인한 제공 사이즈와 겹치는 호칭만 후보에 사용합니다. 옵션의 disabled 표시는 색상 선행 선택 때문에 생길 수 있으므로 재고 판정으로 단정하지 않습니다.

입던 옷과의 차이·실측 추천 점수·더 큰/작은 착용감은 계산하지 않습니다. 참고 후보는 브랜드·상품명 순이며 “실측 미확인”, 가이드 범위, 시즌, 출처와 확인일을 표시합니다. 상품 종류는 비교 가능한 범위와 2단계 선택을 따르고, 계절 선택 시 이름에서 해당 계절을 확인할 수 있는 상품만 사용합니다. “다른 원단” 조건은 자료가 부족하므로 보세 후보를 보류합니다. 브랜드 가이드의 시즌과 상품 시즌은 다를 수 있으므로 카드와 원문을 함께 확인해야 합니다. 재고·판매 상태는 실시간 연동하지 않습니다.

실측 결과의 브랜드 선택과 별개로 보세 영역 안에서 참고 후보 브랜드를 고르고 12개씩 더 볼 수 있습니다. 이 영역은 직접 구매/저장을 제공하지 않고 상품 상세로 연결합니다. 기존 사용자 저장 DB와 실측 DB는 변경하지 않았습니다.

## 데이터 부담과 갱신

추가 JSON 7개는 총 1,121,311바이트(약 1.12MB)이며 gzip 합계는 129,121바이트(약 129KB)입니다. 사진과 기존 앱/OCR 자원은 제외한 수치입니다. 실제 전송량은 서버 압축과 캐시에 따라 달라집니다.

첫 화면에서는 이 JSON을 요청하지 않습니다. 키를 입력하고 결과를 볼 때만 가이드와 해당 상품 종류 파일을 불러오고, 현재 탭에서는 재사용합니다. 사진은 외부 상품 이미지 주소를 사용해 12개씩 지연 로드하며 복제 저장하지 않습니다. 원문 HTML 수집 캐시는 Git/배포에서 제외합니다.

데이터 양보다 시즌별 표 변경, 브랜드 명칭/베베 구분, 품절·신상품 갱신이 관리 부담입니다. 자동 갱신 작업을 예약하지 않았습니다. 필요할 때 실행합니다.

```sh
npm run harvest:mona -- --refresh
npm test
npm run build
```

`--refresh`는 공개 페이지를 다시 확인합니다. 옵션 없이 실행하면 수집 캐시와 기존 확인일을 재사용합니다. 오류 내역과 제외 근거는 `research/mona-review-2026-11-24.json`, 원본 목록은 `research/mona-catalog-list-2026-11-24.json`, 배포용 최종 데이터는 `public/mona/`입니다. 원본 목록에는 검수 이전 항목이 포함될 수 있어 최종 수량은 index.json을 기준으로 합니다.

수집/파서는 `scripts/harvest-mona.mjs`, `scripts/mona-source.mjs`입니다. 매칭/UI는 `public/mona-reference.js`, `.css`입니다. 자동 테스트는 모델 사례 배제, 불명확한 범위 배제, 체중 불일치, 호칭 경계, 옵션 미확인, 계절/원단 조건, 실제 수집 데이터의 일관성을 포함합니다.
