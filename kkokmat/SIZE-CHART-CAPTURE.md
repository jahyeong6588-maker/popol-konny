# 사이즈표 캡처 비교 (2026-11-24)

1단계의 **사이즈표 캡처**에서 옷 종류와 표 언어(한국어/영어)를 선택하고 PNG·JPG·WebP 이미지(10MB 이하)를 고릅니다. 표에서 읽어온 사이즈를 고르고, 비교 부위·원본 단위(cm/mm)·단면/둘레 기준·치수 값을 수정할 수 있습니다. 원본 확인란과 “확인한 치수를 기준으로 사용”을 거쳐야 다음 단계로 갑니다. 이후 값을 고치면 재확인이 필요합니다.

이미지와 OCR 원문은 브라우저 메모리에서만 처리하며 서버에 전송하거나 계정에 저장하지 않습니다. 확인한 숫자는 기존 직접 입력 기준으로 비교하고, 사용자가 저장하면 해당 치수를 기존 옷장/비교 저장 흐름으로 보관합니다. 이미지 자체는 보관하지 않습니다. 별도 AI API 키나 서버 비밀키는 필요 없습니다.

## 구현과 실행

- `public/chart-capture.js`, `.css`: 이미지 선택, 브라우저 OCR, 원본/인식 텍스트 확인 및 값 수정.
- `public/size-chart.js`: 행/열 변환, 비교 부위 매핑, 사용자 확인 값 검증. TSV 좌표로 빈 셀의 열 위치를 유지합니다.
- `scripts/prepare-ocr.mjs`: 고정된 npm 의존성에서 OCR worker·WASM·언어 모델 및 라이선스 자료를 `public/vendor/ocr/`에 준비합니다. 생성 파일은 Git 제외입니다.
- OCR은 Tesseract.js 7.0.0으로 같은 origin의 자원만 로드합니다. 한국어와 영어 모델은 표 언어에 따라 하나씩 사용합니다. 처음에는 모델을 내려받는 시간이 필요하며 취소·오류·90초 시간 제한을 제공합니다.
- `npm ci` → `npm run build`에 자원 준비가 포함됩니다. 정적 `node server.mjs`만 사용할 경우 먼저 `npm ci`와 `npm run prepare:ocr`를 실행합니다.
- 원본 `public/`와 Worker·DB 구조는 기존 실행 문서를 따릅니다. 캡처 비교를 위해 DB 마이그레이션을 추가하지 않았습니다.

## 비교 기준과 한계

총장(세트에서 어느 부위인지 불명확), 가슴(단면/둘레 미명시)처럼 모호한 항목은 자동 확정하지 않습니다. 사용자가 비교 부위를 지정하거나 비교 안 함으로 남깁니다. 인심·바지 총장, 어깨선 소매·등 중심 소매는 별도 필드입니다. 명시한 둘레만 2로 나누고 mm는 cm로 변환합니다. 누락 치수와 범위값을 임의로 추정하지 않습니다.

같은 필드 중복 매핑, 숫자가 아닌 인식값, 부적절한 둘레 변환, 범위를 벗어난 값은 거부합니다. 의류는 알려진 치수 2곳 이상이 필요하며 모자·양말은 1곳입니다. 복잡한 합쳐진 셀, 회전·흐림, 여러 표가 섞인 이미지의 자동 구분은 제한적입니다. 사이즈표 부분만 잘라 올리거나 인식 텍스트를 수정해 다시 표로 만들 수 있습니다.

## 확인한 내용

실제 생성한 한국어 사이즈표 PNG를 브라우저에 입력해 사이즈 행/항목 인식을 확인했습니다. `27`을 `2/`로 읽은 값을 `27`로 수정하고, 확인 전 진행 차단 → 확인 후 2단계 진입 → 결과 표의 기준값 27/38/26 반영까지 검증했습니다. 이는 인식 정확도를 보장하는 뜻이 아니며 원본 대조가 필수입니다. 테스트는 가로/세로 표, cm/mm와 둘레 환산, 불명확한 항목, 중복 매핑, 빈 셀 위치 보존을 포함합니다.
